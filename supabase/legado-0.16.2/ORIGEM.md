# Configuração original do RPG Master Set 0.16.2

Cópia de `downloads/configuracao/` em
`retromaster09-ai/RPG-Master` no commit
`b0f6ab85e2bf1b7165097b1747fac829330a006d`. Os arquivos foram
preservados sem alterações.

A pasta documenta a configuração incremental do Supabase entre as
versões antigas e a 0.16.2. Ela serve de referência para recuperar as
políticas, as funções e o controle de revisões. Os scripts históricos
têm pré-requisitos e precisam ser revisados em conjunto antes de
montar as migrações de um projeto novo. O SQL foi lido localmente e
não foi executado no Supabase de produção.
