# RPG Master — arte de interface

Emblema de livro e dado e ilustração de entrada originais gerados para o projeto. O emblema transparente é usado pelo widget de marca e pelo gerador flutter_launcher_icons para os recursos Android/Windows. A ilustração de entrada é uma cena original; não representa uma capa obrigatória de campanha. As imagens escolhidas pelos jogadores não são incluídas nesses arquivos.

`adventurers.png`: ilustração original gerada para o cabeçalho de campanhas, com quatro aventureiros adultos enfrentando um dragão. Referências visuais de anime fornecidas pelo usuário; personagens originais.

- `login-party.webp` — ilustração original do login, com uma cartógrafa, um narrador e
  um castelo de papel que surge de um caderno de campanha. Gerada para o projeto em anime 2D e
  exportada em WebP a 1536 × 1024.

- `login-party-portrait.webp` — adaptação vertical aprovada da mesma cena,
  com a mesa estendida para acomodar o formulário no celular.
